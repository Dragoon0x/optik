# /critique — UX Design Review

Evaluate the interface from a user experience perspective, beyond code quality.

## What /critique Examines

**Visual Hierarchy:** Is it clear where to look first, second, third? Is there a single focal point? Do size, weight, color, and position work together or fight each other?

**Information Architecture:** Is content organized logically? Can users find what they need? Is the navigation clear? Are related items grouped?

**Emotional Resonance:** Does the design feel intentional? Does it match the brand's personality? Would a user trust this interface? Is there anything memorable?

**User Flow:** Are CTAs clear and prominent? Is the path from entry to action obvious? Are there dead ends? Is there cognitive overload?

## Output
Provide specific, actionable feedback organized by category. Reference specific elements. Suggest concrete improvements. Do not give vague praise — every statement must be either a specific problem or a specific strength.
