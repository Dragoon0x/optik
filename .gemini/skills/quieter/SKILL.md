# /quieter — Reduce Visual Aggression

For designs that try too hard:

1. **Reduce color intensity** — Lower saturation 10-20%. Replace neon with muted versions.
2. **Soften contrast** — If background is pure black, shift to dark gray. If text is pure white, use off-white.
3. **Slow motion** — Increase durations by 50%. Replace bouncy easings with smooth ones.
4. **Add whitespace** — Increase section padding. Add breathing room between elements.
5. **Remove one thing** — Find the most aggressive element and remove or mute it.

The goal: keep the personality but make it comfortable to sit with.
