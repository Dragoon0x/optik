# /align — Alignment Verification

Scan for alignment inconsistencies:
- Do all section headings start at the same x-position?
- Are card grids properly aligned?
- Do text blocks share a consistent left edge?
- Are centered elements truly centered?
- Do images align with text baselines?

Report misalignments with pixel measurements and fixes.
