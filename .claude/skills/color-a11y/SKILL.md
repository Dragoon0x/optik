# /color-a11y — Color Accessibility Matrix

Generate a contrast matrix:
- Test every text color against every background color
- Report AA/AAA pass/fail for each combination
- Flag any combination used in the actual code that fails
- Suggest closest passing alternative for failures

Output as a visual matrix table.
