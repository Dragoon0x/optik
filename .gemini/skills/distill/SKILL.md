# /distill — Strip to Essence

Remove complexity that doesn't earn its place:

1. List every visual element (borders, shadows, gradients, icons, decorations)
2. For each, ask: does removing this hurt clarity or brand?
3. If no, remove it
4. If unclear, remove it and check if anyone would miss it

Target: the version that communicates the same message with the fewest elements. This isn't minimalism for aesthetics — it's information efficiency.
