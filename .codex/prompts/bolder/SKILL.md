# /bolder — Amplify Boring Designs

For designs that are technically correct but forgettable:

1. **Increase type contrast** — Make headlines 20-30% larger. Increase weight difference between heading and body.
2. **Intensify color** — Push the dominant color harder. Add a sharp accent. Increase saturation.
3. **Add motion** — Entrance animations, hover effects, scroll reveals. One memorable transition.
4. **Enlarge key elements** — Make the hero bigger. Make CTAs more prominent. Increase whitespace.
5. **Break the grid** — One element that breaks the expected pattern. An asymmetric layout choice. An overlapping element.

The goal: make someone remember this interface tomorrow.
