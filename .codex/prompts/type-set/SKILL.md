# /type-set — Complete Type System

One-shot typography setup:
1. Generate type scale (default: Major Third 1.250)
2. Select font pairing (based on project aesthetic)
3. Set line heights per level
4. Add letter-spacing for headings and all-caps
5. Define heading margins for vertical rhythm
6. Output as CSS custom properties + utility classes

This combines /type-scale + /type-pair + /type-rhythm into a single operation.
